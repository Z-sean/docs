## 流程概述
- CSS 的工作流程可以粗拆成三步：选择元素 → 计算样式（computed style）→ 渲染页面。
- 浏览器先解析 HTML/CSS，找到“哪些规则命中了哪些元素”，再按优先级和继承关系合并，最后得到用于布局与绘制的实际值。

> 样式来源不止一种。浏览器默认样式（user agent stylesheet）、用户样式、作者样式会一起参与层叠。前端日常主要处理作者样式，但很多“为什么这个标签默认长这样”，本质上是浏览器默认样式在起作用。

## 样式失效原因
- 没选中：选择器根本没匹配到元素
- 被覆盖：层叠优先级更低
- 不能继承
- 值被重算：写的是声明值，最后渲染的是计算值 / used value
- 条件不成立：媒体查询、伪类状态、父容器约束未满足


## 常见错误写法习惯
- 没生效 = 优先级错误：高频错误一般是选择器没选中
- 滥用`!important`：会破坏后期维护
- 混淆声明值/计算值/实际值：例如百分制单位是基于父容器，错误使用会导致尺寸错误
- 误判继承关系
