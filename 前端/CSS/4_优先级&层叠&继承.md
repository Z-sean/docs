## CSS样式冲突
- CSS 冲突的本质不是“谁写得更后面”，而是浏览器按来源、!important、优先级（specificity）、书写顺序和继承规则，逐层裁决最终样式。

## 核心定义
- 层叠（cascade）是浏览器决定“多个样式同时命中时谁生效”的总规则；
- 优先级（specificity）是其中一环，用来比较选择器权重；
- 继承（inheritance）决定某些属性是否从父元素传给子元素。

> CSS冲突的判断流程
> 先看样式来源和 !important → 再比 specificity → 再看书写顺序 → 最后看该属性是否可继承。

A：
```css
.card .title {
  color: blue;
}

#app .card .title {
  color: red;
}
```
B：
```css
.card-title {
  color: blue;
}

.card-title.is-danger {
  color: red;
}
```

- B将样式绑定在状态上，更有利于维护
- B写法的边界更清晰

## 常见错误习惯
- 依赖使用优先级排错
- 使用`！important`当做万能修复
- 过度嵌套选择器
- 继承误判
