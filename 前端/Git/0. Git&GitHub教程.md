#

- Git用于管理本地仓库，包括历史代码与新的代码

- GitHub是远程仓库，用于跨平台存储

## 第一步：配置GitHuB

- 安装Git后，建议你首先配置自己的用户名与邮箱地址，这是Git每一次提交都会做的事情

```bash
$ git config --global user.name "XXX"
$ git config --global user.email XXX@example.com
```

- 为GitHuB提交上传代理
  - 当出现连接github速度慢时，可以为GitHub设置代理，建立快速连接通道
