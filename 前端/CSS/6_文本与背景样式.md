## 定义
- 文本控制：字体、行高、字距、对齐、溢出处理
- 视觉容器控制：背景、边框、圆角、阴影等表面样式

> 通过调整行高，字体来凸显重点，影响阅读效率
> 通过调整边框样式，在结构上表达什么是主要信息，什么是次要信息

```css
.card-title {
  font-size: 18px;
  line-height: 1.5;
  font-weight: 600;
}

.desc {
  color: #666;
  line-height: 1.6;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;


.multi-line {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
  overflow: hidden;
}}



.button {
  padding: 10px 16px;
  border: 1px solid #1677ff;
  border-radius: 8px;
  background: linear-gradient(180deg, #4096ff, #1677ff);
  color: #fff;
  box-shadow: 0 4px 12px rgb(22 119 255 / 20%);
}
```


## 常见错误写法习惯
- 行高 = 字号，文本会拥挤
- 省略号条件不完整
`
overflow: hidden
white-space: nowrap
text-overflow: ellipsis
`
- 阴影滥用，吸引了对内容的注意力
- 背景图只做了显示，没有裁切
