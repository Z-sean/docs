## 定义
- `Grid` 布局的本质是“自上而下”的**二维空间规划**引擎，它将网页视为坐标系，通过精确定义网格轨道（Tracks）来决定元素的绝对区域，而不是像 `Flex` 那样被动依赖内容去挤占空间。

---

## 是什么
- Flex 是“一维内容驱动”（主导单轴流动），Grid 是“二维容器驱动”（主导坐标系规划）。 Grid 首先划分好空间的“坑位”，再把内容填进去，适合页面骨架搭建。


```css
.gallery {
  display: grid;
  gap: 20px;
  /* 核心：自动计算列数。每列最小 250px，空间富裕时等比放大铺满剩余空间 */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```

## 常见错误排查
- 网格被内容“撑爆”
  - 网格轨道（Grid Tracks）的默认最小尺寸也是 auto（即内部内容的固有尺寸）。如果内部有个超宽的 table 或不换行长文本，1fr 会失效被撑破。解法：在定义列时，使用 minmax(0, 1fr) 替代单纯的 1fr，强制重置网格轨道的最小尺寸边界限制。
- 滥用Grid导致语义降级[仅仅为了垂直居中一个 Icon，或者做一个简单的线性 Tab 导航条而开启 Grid。]
  - 一维线性排列用 Flex，二维区域划分用 Grid”。微观组件内部流用 Flex，宏观页面区块分布用 Grid
