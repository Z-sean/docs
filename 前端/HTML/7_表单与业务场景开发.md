## 核心概念
- `form` 是表单的提交容器，浏览器会以它为边界收集带 
- `name` 的控件值并发起提交。
- `input、textarea、select` 是数据入口
- `button` 是行为触发器。
### 语义说明
- `label` 不只是文字说明，它**决定可点击范围、**可访问性（a11y）和表单可用性；
- `name` 是提交时的字段名，没有它，后端基本收不到值；
- `required、email` 等类型还会触发浏览器原生校验，减少无效请求。

```html
<form action="/login" method="post">
  <label for="username">账号</label>
  <input id="username" name="username" type="text" required>

  <label for="pwd">密码</label>
  <input id="pwd" name="password" type="password" required>

  <button type="submit">登录</button>
</form>
```

## 常见注意事项
- 只写 `placeholder` 不写 `label`：提示会消失，读屏软件也不友好。
- 不写 `name`：界面可以输入，提交却拿不到值。
- 不理解 `button` 默认行为：筛选区的“重置/查询”按钮若都用默认按钮，常导致误提交。
- 单选框、复选框乱写：同组选项要共享同一个 `name`。
