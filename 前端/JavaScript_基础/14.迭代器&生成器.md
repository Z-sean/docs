# 迭代器&生成器

## Q:迭代器是什么？

- 帮助我们对某个数据结构进行遍历的**对象**,设计的目的是对**容器进行迭代**
- 迭代器需符合迭代器协议：
  - 迭代器协议定义了产生一系列值的方式：使用next()方法
- next()
  - **无参函数**，返回一个拥有两个属性的对象
    - done:若当前有数据返回，为false，无数据返回，返回true
    - value:当前返回的值

```js
const arr = ["a","b","c"]

const arrIterator = {
    let index = 0
    next(){
        if(this.index <arr.length){
            return {
                done:false,
                value:arr[this.index++]
            }
        }else{
            return {
                done: true
                value:undefined
            }
        }
    }
}

let index = 0
function createArrayIterator(arr){

    return {
        next(){
            if(this.index <arr.length){
                return {
                    done:false,
                    value:arr[this.index++]
                }
            }else{
                return {
                    done: true
                    value:undefined
                }
            }
        }
    }
}
```

- 无限迭代器


## Q:什么是可迭代对象

- 观察发现:数组，索引，迭代器生成对象三者具有强关联
  - 由此:将三者封装在同一个对象中
- 可迭代对象；
  - 对象
  - 实现了可迭代协议(≠迭代器协议)
  - 该协议要求必须实现Symbol.iterator方法，该方法返回一个迭代器

```js
const iteratorObj = {
  arr: ["a", "b", "c"],

  [Symbol.iterator]: function () {
    let index = 0;
    return {
      next: () => {
        if (index < this.arr.length) {
          return {
            done: false,
            value: arr[index++],
          };
        } else {
          return {
            done: true,
            value: undefined,
          };
        }
      },
    };
  },
};
```

- next使用箭头函数，this与function相同，指向函数调用者
- 将对象设计为可迭代对象，可以通过`for...of`遍历
- 原生可迭代对象：
  - Array/Map/Set/String/Arguments对象/NodeList集合
- 可迭代对象应用
  - 通过实现可迭代协议，得以支持：
    - 展开语法
      - 对象的展开不是使用的可迭代协议实现的
    - 解构语法
      - 对象的解构不是使用可迭代协议实现的
    - for...of循环
- 自定义类的可迭代性
  - 通过在类中实现[Symbol.iterator]方法，实现类的可迭代性

```js
class classRoom {
  constructor(roomName, roomType, students) {
    this.roomName = roomName;

    this.roomType = roomType;

    this.students = students;
  }

  entry(newStu) {
    this.students.push(newStu);
  }
  [Symbol.iterator]() {
    let index = 0;
    return {
      next: () => {
        if (index < this.students.length) {
          return { value: this.students[index++], done: false };
        } else {
          return { done: true, value: undefined };
        }
      },
    };
  }
}
```

- return():该方法用于监听提前终止的迭代器,也需要返回一个符合迭代器协议的对象

```js
[Symbol.iterator](){
    //...
    return(){
        //...
        return {
            done:true,
            value:undefined
        }
    }
}

```

## Q:什么是生成器

- 是在Es6中新增的函数控制/使用方案，可以灵活控制函数什么时候执行，什么时候暂停
- 生成器是由生成器函数产生的
- 生成器函数是函数，与普通函数有以下区别：
  - 生成器函数在function后有\*
  - 生成器函数可以通过yield关键字控制函数执行流程
  - 生成器函数的返回值是一个生成器对象
    - 生成器是一种特殊的迭代器
- 执行生成器函数时，默认不会立即执行
  - 生成器函数返回一个迭代器，若需要生成器函数执行，需要调用next()，每调用一次，会执行在下一个yield关键字前

```js
function* text() {
  console.log("第一次执行");
  yield;

  console.log("第二次执行");
  yield;

  console.log("第三次执行");
  yield;
}

const gen = text();

gen.next();

gen.next();

gen.next();
```

## Q:生成器函数的执行流程

- yield：暂停函数执行
- return：停止函数执行
- 当我们需要在函数中返回值时，若使用return，会导致后续的yield失效
- 若需要在函数中返回值，则直接在yield后跟上返回值即可

> [!note] yield的作用
>
> - 数据产出:yield右边的表达式会被计算并包装在{done:..,value:..}对象中
> - 数据接收:yield是下一次next()被唤醒时，用于接收参数的占位符
> - 暂停生成器函数运行
> - yield\* 会暂停当前生成器函数运行，并且把后续所有的next()转发给后面的可迭代对象。

## Q:生成器的使用

- 生成器函数可接受参数，作为第一段执行代码的参数
- next()可以传递参数，通过yield接收参数

```js
function* foo(num) {
    const value = 100*num
    console.log(value)
    const n = yield value

    consr value2 = n*2
    console.log(value2)
}
const gen1 = foo(10)

gen1.next(5)
```

- 第一次执行时，通过foo()传递参数，(不能通过next，因为next()传递的是上一次执行的结果，不能在第一次执行时就作为参数传递)
- 第二次执行通过next()传递参数5代替第一次的结果
- `yield xxx`表示将xxx作为当前执行的next()函数返回的对象的value值，并将函数在此处暂停，而yield表达式的结果，由下一次next()时传入的参数决定

- return()函数：
  - 提前终止生成器函数执行
    - 若在生成器函数执行过程中没有return()，在最后一次执行后，自动执行return()
    - 若在生成器函数执行过程中，显式执行了return()，则后续的yield失效

- throw()
  - 异常抛出代码
  - 若有捕获机制，则不影响后续代码执行
  - 若没有捕获机制，那么生成器会提前终止

## 生成器代替迭代器

- 生成器就是特殊的迭代器
  - 直接使用生成器来简化迭代器输出

```js
function createArrayIterator(arr) {
  let index = 0;
  return {
    next: function () {
      if (index < arr.length) {
        return {
          done: false,
          value: arr[index++],
        };
      } else {
        return {
          done: true,
          value: undefined,
        };
      }
    },
  };
}
function* createArrayIterator(arr) {
  //   let index = 0;
  //   yield arr[index++];
  //   yield arr[index++];
  //   yield arr[index++];
  //   //...

  //   for (const item of arr) {
  //     yield item;
  //   }

  yield* arr;
}
```

- yield\* 后必须跟一个可迭代对象,其作用是把可迭代对象遍历结果输出给后续的next()

```js
class classRoom {
  constructor(roomName, roomType, students) {
    this.roomName = roomName;

    this.roomType = roomType;

    this.students = students;
  }

  entry(newStu) {

  // };

    yield* this.students;
  }
}
```

## 异步函数的处理方式

- 要求:多次请求发送
- 方案一：多次回调

```js
requestData().then((res) => {
  requestDate(res + "aaa").then((res) => {
    requestData(res + "bbb").then((res) => {
      //...
    });
  });
});
```

- 方案二：then链式调用

```js
requestData()
  .then((res) => {
    return requestData();
  })
  .then((res) => {
    //...
  });
```

- 方案三：Promise+生成器

```js
function* getData() {
  const res1 = yield requestData(xxxx);
  const res2 = yield requestData(xxxx + xxx);
  //...
}

const gen = getData();
gen.next().value.then((res) => {
  return gen.next(res).value.then((res) => {
    return gen.next(res).value.then((res) => {
      //...
    });
  });
});
```

- 由于多次网络对话需要存储每一次的网络数据，所以使用resx来保存每一次网络请求的数据，再在下一次调用时把数据传给下一次网络请求
- 解释:**yield就像一个旋转门**，上一段代码执行时，结果加入门中，下一次代码执行时，若有参数进入，则进入旋转门，上一次的结果出去
- requestData()返回一个Promise，被包装在对象的value属性中，我们通过不断调用生成器函数控制请求发送
- 优化:对每一次的生成器的重复操作就行自动化包装

```js
//1. 首先需要拿到生成器函数的结果：生成器对象
function execGenerator(genFn){
  const generator = genFn()

  //2. 自动化执行逻辑
  //2.1 接收每一次网络请求获取的数据
  //2.2 对获取对象进行判断，若为true，说明遍历结束，返回结果
  //2.3 若不为true，说明遍历没有结束，继续调用next，也就是继续执行自动化函数。而每一次的网络请求结果都是传递在then中的
  fucntion exec(res){
    const result = generator.next(res)
    if(result.done) return result.value
    result.value.then(res=>{
      exec(res)
    })
  }
  //3. 执行自动化函数
  exec()
}
```
