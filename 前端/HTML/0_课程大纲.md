# HTML 课程大纲（10节）

> 目标：基于就业导向，在 **10 节课程** 内系统覆盖 HTML 的核心知识点，并让学习顺序符合真实前端开发路径。 课程定位：**不是标签背诵课**，而是围绕“写出语义正确、结构清晰、可访问、能进入项目”的 HTML 能力展开。 适合人群：准备进入前端岗位、补基础、或想把 HTML 从“会写几个标签”提升到“能服务项目开发”的学习者。

---

## 课程总目标

学完这 10 节课，应该达到以下结果：

1. 能独立写出结构合理的页面骨架。
2. 能根据内容选择合适的语义标签，而不是满屏 `div`。
3. 能完成常见业务表单页面，并理解原生表单机制。
4. 能写出基础可访问的 HTML 结构。
5. 能理解 HTML 在 Vue / React 项目中的真实作用。
6. 能完成一个接近求职作品标准的静态页面结构开发。

---

# 第1节：HTML 在前端中的定位与基本文档结构

## 课程目标

建立正确认知：HTML 不是“页面样式语言”，而是 **网页内容与结构层**。

## 核心内容

- 什么是 HTML，负责什么，不负责什么
- HTML、CSS、JavaScript 三者分工
- 一个网页从内容到浏览器渲染的大致过程
- HTML 基础文档结构
    - `<!DOCTYPE html>`
    - `<html>`
    - `<head>`
    - `<meta>`
    - `<title>`
    - `<body>`
- 常见编辑器与浏览器开发调试方式
- HTML 注释与书写规范
    

## 本节重点

- 理解“HTML 是结构，不是表现”
- 理解浏览器最终读到的是文档结构
    

## 本节练习

- 手写一个最基础的 HTML 页面
- 创建一个“个人介绍页”的基础骨架
    

## 常见错误

- 把 HTML 当成“做样式的东西”
- 不理解 `head` 与 `body` 的职责
- 文档结构不完整，直接开始乱写标签

---

# 第2节：常用文本语义与内容组织

## 课程目标

学会表达页面中的“内容含义”，而不是只会堆文字。

## 核心内容

- 标题标签：`h1 ~ h6`
- 段落与文本：`p`、`br`、`hr`
- 强调与重要性：`strong`、`em`
- 补充语义：`small`、`mark`、`blockquote`、`code`
- 文本结构如何服务阅读与可维护性
- 标题层级与内容层级的关系
    

## 本节重点

- 标题不是为了变大字体，而是为了表达层级
- `strong` 和 `em` 是语义，不只是视觉加粗和斜体
    

## 本节练习

- 用正确标题层级写一个“技术文章页面”正文区域
- 用语义标签整理一段商品介绍文案
    

## 常见错误

- 页面里多个 `h1` 乱用
- 所有文本都只用 `div`、`span`
- 用 `br` 代替段落结构

---

# 第3节：列表、链接与导航结构

## 课程目标

掌握页面中最常见的信息组织与跳转方式。

## 核心内容

- 无序列表：`ul`、`li`
- 有序列表：`ol`、`li`
- 描述列表：`dl`、`dt`、`dd`
- 链接：`a`
    - `href`
    - 新窗口打开
    - 锚点链接
    - 邮箱/电话链接的基本概念
- 导航的语义组织
- 菜单、目录、侧边栏为什么常常是列表结构
    

## 本节重点

- 一组同类导航项，本质上通常就是列表
- 链接负责跳转，按钮负责操作，不要混用
    

## 本节练习

- 写一个博客网站顶部导航
- 写一个文章目录区
- 写一个“课程目录列表”页面
    

## 常见错误

- 导航不用列表结构
- 用 `span` 模拟链接
- 链接文字含义模糊，只写“点击这里”

---

# 第4节：图片、多媒体与内容嵌入

## 课程目标

掌握媒体内容的正确引入方式，并建立基础可访问意识。

## 核心内容

- 图片标签：`img`
    - `src`
    - `alt`
    - `width` / `height`
- 图片在内容中的角色
- 装饰图与内容图的区别
- `figure`、`figcaption`
- 多媒体基础了解：`audio`、`video`
- 内嵌内容基础了解：`iframe`
    

## 本节重点

- `alt` 不是摆设，它决定图片语义是否完整
- 图文组合要考虑结构，而不只是显示出来
    

## 本节练习

- 写一个带封面图和图注的文章页片段
- 写一个商品卡片列表，包含商品图、标题、价格
    

## 常见错误

- 图片没有 `alt`
- 图文关系混乱
- 只关注图片显示，不关注内容含义

---

# 第5节：语义化布局与页面结构设计

## 课程目标

从“会写标签”升级到“会搭页面骨架”。

## 核心内容

- 页面分区语义标签
    - `header`
    - `nav`
    - `main`
    - `section`
    - `article`
    - `aside`
    - `footer`
- 什么叫页面骨架
- 首页、文章页、后台页、商品详情页的常见结构思路
- `div` 的正确定位：通用容器，而不是万能语义替代品
    

## 本节重点

- 先搭结构，再谈样式
- 页面结构要和内容类型匹配
    

## 本节练习

- 手写一个博客首页骨架
- 手写一个商品详情页骨架
- 手写一个后台管理页骨架
    

## 常见错误

- 全页面只用 `div`
- `section`、`article`、`aside` 分不清
- 页面结构靠视觉猜，不从内容出发

---

# 第6节：表格与结构化数据展示

## 课程目标

理解表格的适用场景，避免乱用或滥用。

## 核心内容

- 表格的适用场景
- 基础标签：`table`、`tr`、`td`、`th`
- 表头与表体：`thead`、`tbody`
- 表格标题：`caption`
- 合并单元格基础：`rowspan`、`colspan`
- 表格语义与可读性
    

## 本节重点

- 表格用于展示“有行列关系的数据”
- 不要再用表格做页面布局，那是时代遗迹
    

## 本节练习

- 写一个课程表
- 写一个订单列表
- 写一个后台用户数据表
    

## 常见错误

- 数据表不用 `th`
- 表头与数据没有区分
- 拿表格做整个页面布局

---

# 第7节：表单基础与业务场景开发

## 课程目标

掌握最贴近真实工作的 HTML 核心能力之一：表单。

## 核心内容

- 表单标签：`form`
- 常见输入控件：
    - `input`
    - `textarea`
    - `select`
    - `option`
    - `button`
- 常见输入类型：
    - `text`
    - `password`
    - `email`
    - `number`
    - `radio`
    - `checkbox`
    - `file`
- 表单字段命名与提交基础
- `label` 与控件关联
- `name`、`value`、`placeholder`、`required`
- 按钮默认行为与表单提交基本机制
    

## 本节重点

- 表单是就业里最常见的 HTML 场景
- 只会做“好看输入框”没用，关键是结构正确、行为正确
    

## 本节练习

- 登录页
- 注册页
- 搜索筛选区
- 收货地址表单
    

## 常见错误

- 只写 placeholder，不写 label
- 不理解 `button` 默认提交行为
- 输入框很多，但没有 `name`

# 第8节：HTML 可访问性基础

## 课程目标

建立“先写对，再增强”的无障碍意识。

## 核心内容

- 什么是可访问性
- 原生 HTML 为什么自带很多可访问能力
- 图片 `alt`
- 表单 `label`
- 按钮与链接的语义区别
- 标题层级与页面可读性
- 键盘可访问的基本认知
- ARIA 的定位：补充，不是替代原生语义
    

## 本节重点

- 可访问性的第一步不是背规范，而是不破坏原生能力
- 能用原生语义解决，就不要先拿 ARIA 硬补
    

## 本节练习

- 检查并修改前面课程里的页面，让它更可访问
- 把一个“全是 div 的交互区域”改成语义正确的结构
    

## 常见错误

- 可点击区域用 `div`
- 输入框没有可读名称
- 把 ARIA 当成“高级前端装饰品”乱加

---

# 第9节：HTML 在现代前端项目中的作用

## 课程目标

把 HTML 从“静态页面知识”接到现代开发流程里。

## 核心内容

- Vue / React 项目里为什么仍然离不开 HTML
- 模板 / JSX 最终仍然在描述 DOM 结构
- 组件开发中的语义保留
- HTML 与 SEO 的基本关系
- SSR / 静态页面输出为什么更依赖结构质量
- 常见业务组件的 HTML 基础
    - 导航组件
    - 卡片组件
    - 表单组件
    - 弹窗结构基础
        

## 本节重点

- 框架没有消灭 HTML，反而更考验你是否理解结构语义
- 项目里最容易烂掉的，往往正是最基础的 HTML
    

## 本节练习

- 用 Vue 或 React 思维拆一个静态页面结构
- 分析一个组件页面里哪些地方应该保留原生标签
    

## 常见错误

- 只会写组件，不会思考语义
- 把“能渲染出来”误认为“结构正确”
- UI 库一包就不管底层 HTML 是否合理

---

# 第10节：综合实战与求职标准检验

## 课程目标

通过一个完整项目，把前 9 节内容串起来，并形成面试可讲的成果。

## 核心内容

- 综合项目：从零完成一个多区域静态页面
- 推荐项目方向（三选一）
    
    1. 博客文章详情页
    2. 商品详情页
    3. 企业官网首页
        
- 项目要求
    - 页面骨架完整
    - 标题层级清晰
    - 导航结构合理
    - 图片语义合理
    - 表单结构正确
    - 至少体现基础可访问意识
- 自查清单
    - 有没有滥用 `div`
    - 表单是否有 `label`
    - 图片是否有 `alt`
    - 链接和按钮是否区分
    - 页面分区是否合理
        

## 本节重点

- 求职项目里，HTML 不是拿来炫技的，而是拿来证明你基本功可靠
- 面试官会从结构质量反推你的开发习惯
    

## 本节练习

- 独立完成一个页面结构项目
- 对自己的页面做一次“语义化 + 可访问性”检查
- 输出一份项目说明，解释为什么这样组织 HTML
    

## 常见错误

- 只做视觉，不解释结构
- 项目能跑，但结构混乱
- 不会复盘，导致做完还是不知道自己对错在哪

# 课程配套建议

## 学习节奏建议

- 每周 2~3 节
- 10 节课程可在 4~5 周完成
- 每节课必须配套手写练习，不建议只看不写
    

## 学习方法建议

- 每学完一节，必须做一个小页面片段
- 每 3 节做一次复盘，总结“我为什么要用这个标签”
- 遇到标签时不要先背属性，先问：**它解决什么内容结构问题？**
    

## 输出物建议

整个课程学完后，建议至少保留以下成果：

- 1 个文章页
- 1 个表单页
- 1 个综合页面
- 1 份自己的 HTML 标签使用原则笔记

---

# 最终总结

这套 10 节课的核心，不是把 HTML 学成“标签大全”，而是建立一套符合就业要求的能力路径：

1. 先理解 HTML 的职责。
2. 再掌握常用内容标签。
3. 然后学会组织页面结构。
4. 接着重点突破表单与可访问性。
5. 最后把 HTML 放进现代前端项目和求职作品中。
    

一句话概括：

**HTML 的学习终点，不是会写标签，而是能把页面结构写得正确、稳定、可维护，并且能支撑真实项目开发。**
