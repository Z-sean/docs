#
- 箭头函数不会绑定`this&argument`属性
- 箭头函数不能当做构造函数使用
## 基本使用
### 组成
1. ():参数
2. =>:箭头
3. {}:函数执行体

### 简写
- 当只有一个参数，()可以省略
- 当函数执行体只有一行代码，可以省略{}，该行代码就是返回值
- 若只有一行代码，且返回一个对象类型，需要添加()
```js
var arr = [1,2,3]
arr.filter(item => item % 2 ==0)
    .map(item => item * 2)
    .reduce((prevalue,item)=> prevalue + item)

var bar = () => ({name:"zc",age:18})
```
