## 核心含义
Vue 模板、React JSX，本质仍是在描述 DOM 结构。也就是说，框架**负责组织和更新**，HTML 负责**表达内容关系与交互语义**。
这点在 SEO、SSR（服务端渲染）和 SSG（静态生成）里尤其明显：首屏输出如果结构混乱，搜索引擎、读屏器、甚至后续样式和脚本接入都会变笨。

```html
<article className="card">
  <h2>商品标题</h2>
  <p>商品描述</p>
  <a href="/detail">查看详情</a>
</article>

<form>
  <button type="submit">提交</button>
</form>
```

## 常见错误指南
- 只会写组件，而不想语义：比如组件名叫 Button，底层却是 div，这是伪装，不是抽象。
- 把“能渲染出来”当“结构正确”：视觉对了，不代表 SEO、键盘操作、读屏体验也对。
- UI 库一包就不管底层：库只帮你提速，不能替你思考页面结构。
- 弹窗只顾样式：至少要有标题、内容区、关闭按钮。
