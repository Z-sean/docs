## 无序&有序列表
- `ol`、`ul`、`li`
- 语义：列表表示的是一组同类项
- 无序列表与有序列表的区别在于顺序问题
  - 无序列表的同类项之间没有顺序之分
  - 有序列表之间是有顺序的

## 描述列表
- `d、`dt`、`dd`
- 语义:内容是“术语 / 名称 + 解释 / 描述”这种关系时，用描述列表

## `a`
- 超链接标签，负责导航&跳转
```html
<a href="xxx,com">
```
- `href`表示跳转目标，没有`href`,`a`就不能表示一个链接
  - 目标可以是：
    - 一个网页地址
    - 一个站内路径
    - 一个页面锚点
    - 一个邮箱协议
    - 一个电话协议

## 新窗口打开
```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  访问示例网站
</a>
```
> 新窗口打开外部链接时，通常配合 rel="noopener noreferrer"。
> 当你用 target="_blank" 打开新页面时，新页面可能通过某些机制拿到对原页面的引用。
> 加上 noopener noreferrer 是更稳妥的写法。

## 锚点链接
```html
<a href="#section-reactivity">响应式原理</a>
<h2 id="section-reactivity">响应式原理</h2>
<p>这里是正文内容……</p>
```
> 本质上是对文档内部的结构跳转

## 邮箱&电话链接
```html
<a href="mailto:hello@example.com">发送邮件</a>

<a href="tel:13800138000">拨打电话</a>
```
## 导航的语义组织
- 导航一般具有几个特征：
  - **一组同类项**
  - 每一项之间都可以跳转
- 由此可以推出结构
  - 外层：导航区
  - 内层：列表
  - 列表项内：链接
```html
<nav>
  <ul>
    <li><a href="/">首页</a></li>
    <li><a href="/blog">博客</a></li>
    <li><a href="/projects">项目</a></li>
    <li><a href="/about">关于</a></li>
  </ul>
</nav>
```

### 菜单&目录&侧边栏的结构
- 菜单、目录、侧边栏常常是列表结构
  - 本质上就是：一组相关入口项
  - 特点：
    - 同类
    - 成组
    - 可遍历
    - 常带跳转关系

## 链接负责跳转，按钮负责操作
### 链接场景
- 去文章详情页
- 去用户主页
- 去课程页
- 跳到当前页某一节
- 打开邮箱/电话
### 按钮场景
- 提交表单
- 打开弹窗
- 切换主题
- 删除内容
- 加入购物车
- 加载更多

### 场景混用
```html
<a href="#">删除</a>
<button type="button">去文章页</button>
```
- 考虑是要跳转还是操作

## 示例
```html
<div class="nav">
  <span>首页</span>
  <span>文章</span>
  <span>关于我</span>
</div>

<div class="catalog">
  <div>第一章：HTML基础</div>
  <div>第二章：CSS基础</div>
  <div>第三章：JavaScript基础</div>
</div>

<a href="#">删除这篇文章</a>
```
> 指出这段代码的问题
1. 导航区域缺少语义
  - div.nav是普通容器
  - span也没有表达跳转的目的
2. 目录区域缺少语义
  - div.catalog是普通容器
  - 目录同样适合列表来表示一组同类项
3. 删除行为不应该使用链接标签
  - 行为应该使用button
