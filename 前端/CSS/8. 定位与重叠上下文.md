## 解决什么问题？
- 定位与重叠是为了打破传统文档流，在Z轴方面建立独立的渲染层级来精准控制元素与空间之间的关系与逻辑覆盖

## 定义核心
- 重新认识` position`：脱离与参考系
    - `relative（相对定位）`：自身在文档流中的**原始占位保留**，视觉表现上相对自身偏移。它**是构建 absolute 包含块（Containing Block）的最优解，因为它的副作用最小**。
    - `absolute（绝对定位）`：完全**脱离文档流**，其**尺寸和位置取决于最近的非 static 祖先元素**。
    - `fixed / sticky`：fixed 的**默认参考系是视口**（Viewport）。sticky 是相对定位与固定定位的动态混合体，它依赖于最近的滚动祖先容器，在跨越指定阈值前表现为 `relative`，跨越后表现为 `fixed`。
    - z-index:仅在同一个层叠上下文中有效，不仅 `position: relative/absolute + z-index` 会创建层叠上下文，诸如` opacity < 1`、`transform`、`filter`、`flex/grid` 子元素加 `z-index`，甚至现代 CSS 的 `isolation: isolate` 都会隐式创建新的层叠上下文。

```css
.card-wrapper {
  position: relative; 
  /* 显式隔离层叠上下文，把内部的 z-index 影响限制在当前容器内 */
  isolation: isolate; 
}

.badge {
  position: absolute;
  top: 0; 
  right: 0;
  /* 使用 translate 替代负值定位，不破坏原有盒模型逻辑，方便中心点对齐 */
  translate: 50% -50%;
  z-index: 1; /* 只要在 current stacking context 中最大即可 */
}
```

## 避坑指南
1. `z-index`没反应
    - 检查目标元素是否设置了 `position`（非 static），或者它是否受限于父级一个非常低的层叠上下文中。父级的 `z-index `为 1 时，子级设为 10000 依然会被别的 `z-index: 2` 的元素遮挡
2. `fixed`元素跟随页面滚动
    - 如果 fixed 元素的任意祖先节点设置了 transform、perspective 或 filter 属性，该祖先会立即取代视口（Viewport），成为 fixed 元素的定位参考系。
3. `sticky`吸顶失效
    - 第一，检查` sticky` 元素的祖先节点是否设置了 `overflow: hidden`、`overflow: auto` 或 `overflow: scroll`（这会改变滚动容器的判定）。第二，检查其父容器的高度是否与 `sticky` 元素自身高度完全一致，若没有多余的滚动空间，吸顶效果无从触发。
