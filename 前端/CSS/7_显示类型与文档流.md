## 定义
- display 决定元素以什么盒子参与布局。高频三类是：
  - block：独占一行，可设宽高
  - inline：不独占一行，宽高通常不按块级方式生效
  - inline-block：不独占一行，但可设宽高

> 正常文档流（normal flow）是浏览器默认排版机制：块级元素从上到下排，行内内容从左到右排。所谓“换行”“错位”“不占满一行”，本质都和元素如何进入这套流有关。

```css
.tag {
  display: inline-block;
  min-width: 120px;
  padding: 12px;
  background: #eee;
  border-radius: 8px;
}
```

## 常见错误写法
- 行内元素当做块级元素用
- 视觉错误按照定位问题处理
  - 元素换行，挤压，错位优先看文档流和显示类型，而不是在定位上找问题
- 乱用`overflow:hidden`
- 忽略空白字符影响，
  - `inline-block`元素之间会受空格/换行影响，更适合flex
