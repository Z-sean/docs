# 错误处理方案

- `throw`
  - 抛出异常，抛出后必须解决，否则会导致程序终止运行
- 类型：
  - 字符串：`throw 'error'`
  - 对象：`throw{code:,message:`
  - Error类
    - name:错误名
    - message：错误信息
    - stack：调用栈(用于追溯问题 来源)
  - Error类的子类：
    - RangeError：下标越界
    - SyntaxError:解析语法错误
    - TypeError：类型错误
- 需要注意：抛出异常后，后续代码不会继续执行
- 异常处理方案：
  - 通过`throw`抛出的异常，会沿着调用栈向上抛出异常，若直到顶层（全局）仍然没有捕获处理，会导致整个程序终止
  - `try..catch`用于捕获并处理异常，同时不影响后续的代码执行，处理异常的逻辑写在`catch`代码块中，**对错误进行分流**
    - `finally`该代码块一般执行收尾操作，资源释放，变量初始化等
