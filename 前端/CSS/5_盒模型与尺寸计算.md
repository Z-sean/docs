## 语义核心
盒模型决定的不是“元素有多大”，而是内容、边框、内外间距如何一起参与占位与布局。
## 定义
- 一个元素的可见与占位尺寸，由 `content + padding + border + margin` 共同影响。
- 默认是标准盒模型：`width/height` **只管 content**；
- 设为 `box-sizing: border-box` 后，width/height 包含 padding 和 border。

> **自身多大**：看盒模型
> **最多/最少多大**：看 min/max-width/height
> **和别人隔多远**：看 margin
> **为什么上下间距异常**：常是 margin 塌陷（margin collapsing）
> CSS 布局里，**尺寸不是孤立值，而是约束系统**。

- 推荐写法：
```css
*,
*::before,
*::after {
  box-sizing: border-box;
}

.card {
  width: min(100%, 300px);
  padding: 20px;
  border: 2px solid #ddd;
}
```
- `border-box` 让尺寸更符合直觉，组件更好控
- `min(100%, 300px)` 更适合响应式

```css
.panel {
  width: 100%;
  max-width: 720px;
  min-height: 200px;
}
```
- width 是目标值，max/min 是边界，不是并列关系。

## 常见错误写法习惯
- 把width当做最终占位:默认盒模型下不是最终宽度
- 乱用固定高度:容易导致内容溢出
- 分不清padding和margin
- 忽略margin塌陷
